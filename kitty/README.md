# kitty/

Terminal emulator config. Used as `$terminal` in Hyprland.

## Files

| File | Description |
|------|-------------|
| `kitty.conf` | Font, colors, keybinds, padding |

## Window Rules (set from Hyprland)

| Class | Rule |
|-------|------|
| `kitty` | Opacity 0.85 (active) / 0.77 (inactive) |
| `floatingterm` | Float, center, 720×450, opacity 0.77 |
| `kitty` @ special:magic | Float, center, 1200×750 |
