# fedora-dotfiles

Personal dotfiles for a Fedora Linux setup running Hyprland (Wayland compositor).

## What's in here

**Window manager & desktop**
- `hypr/` — Hyprland config, hyprlock, hypridle, hyprpaper
- `waybar/` — status bar config and styles
- `wofi/` — app launcher
- `dunst/` — notification daemon

**Terminal & shell**
- `fish/` — Fish shell config and functions
- `zsh/` — Zsh config
- `kitty/` — terminal emulator
- `tmux/` — terminal multiplexer

**Editor**
- `nvim/` — Neovim config

**CLI tools**
- `atuin/` — shell history
- `yazi/` — terminal file manager
- `cava/` — audio visualizer
