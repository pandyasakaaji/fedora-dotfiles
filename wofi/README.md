# wofi/

App launcher config (used for drun and clipboard via cliphist).

## Files

| File | Description |
|------|-------------|
| `config` | Wofi options |
| `style.css` | Styling (Tokyo Night Dark theme) |

## Usage

| Keybind | Action |
|---------|--------|
| `Super + Space` | App launcher (drun) |
| `Super + V` | Clipboard history (cliphist pipe) |
